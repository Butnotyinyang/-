# 面向CPU低算力场景的动态ρ衰减轻量化SAM算法
## 项目简介
原始SAM优化器泛化性能优于SGD、Adam，但双重前向、反向传播带来较大计算开销。现有轻量化SAM改进方案均基于GPU并行场景设计，无法在普通CPU设备完成高效训练。
本文提出动态扰动半径线性衰减DSAM轻量化优化器，训练前半段固定扰动半径以保留SAM的泛化优势，后半段线性衰减扰动幅度，并引入高损失样本筛选机制降低计算量，适配无GPU笔记本、课程实验等低算力环境。
本仓库提供完整可运行的PyTorch代码，复现SGD、Adam、原始SAM、DSAM四种优化器对照实验。

## 环境配置
1.Python版本：3.9
2.依赖库：torch 2.0、torchvision、matplotlib、numpy
3.一键安装命令：
  pip install torch torchvision matplotlib numpy

## 文件说明
1. test.py：主训练代码，包含数据集加载、轻量化CNN网络、四类优化器实现、训练日志记录、精度曲线绘制功能
2. *.train_log.txt：各优化器24轮完整训练日志，记录每轮训练精度、测试精度、单轮训练耗时
3. *.acc_curve.png：各优化器训练精度变化可视化曲线图

## 运行步骤
1. 打开test.py，修改参数 OPT_SELECT 切换优化器，可选参数：sgd / adam / sam / dsam
2. 执行命令运行代码：python test.py
3. 程序自动输出对应优化器的日志文件与精度曲线图片

## 统一实验超参数
1.数据集：CIFAR-10
2.骨干网络：轻量化双层卷积CNN
3.总训练轮数 EPOCHS = 24
4.批次大小 BATCH_SIZE = 64
5.全局学习率 LR = 0.001
6.SAM/DSAM初始扰动半径 BASE_RHO = 0.02

## 实验结果汇总
| 优化器 | 最终训练准确率 | 最终测试准确率 | 平均单轮耗时 |
|--------|----------------|----------------|--------------|
| SGD    | 50.44%         | 51.95%         | ≈25.2s       |
| Adam   | 80.92%         | 78.94%         | ≈31.4s       |
| SAM    | 80.31%         | 77.96%         | ≈40.2s       |
| DSAM   | 82.36%         | 79.97%         | ≈40.0s       |

## 实验核心结论
1. DSAM泛化性能最优，测试精度高于Adam与原始SAM，训练、测试精度差值最小，抑制过拟合效果更强；
2. 训练前12轮DSAM收敛曲线与原始SAM基本重合，证明分段固定扰动半径设计可完整保留SAM原有收敛特性；
3. 动态衰减策略与高损失样本筛选降低浮点运算量，DSAM单轮CPU训练耗时略低于原始SAM，实现轻量化优化；
4. 整套实验框架仅依赖CPU即可运行，硬件门槛低，适用于深度学习课程实验、小型离线图像分类任务。
